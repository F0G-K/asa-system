ASA System

自动化安全评估系统 — 前端页面原型（暗色主题）

认证
登录页
/login
用户登录，输入用户名和密码进入系统。
认证
系统初始化
/system/init
首次使用时创建管理员账户。
业务模块
项目管理
/projects
查看、创建、启动、停止安全评估项目。
业务模块
实时监控
/projects/:id/monitor
评估阶段进度、角色任务、消息和日志实时查看。
业务模块
漏洞管理
/projects/:id/vulnerabilities
项目发现的漏洞列表，支持风险等级和验证状态筛选。
业务模块
攻击路径
/projects/:id/attack-paths
将漏洞串联成攻击链路，展示攻击者可能的渗透路径。
业务模块
评估报告
/projects/:id/report
评估报告预览与下载，支持 Markdown 和 HTML 格式。
系统管理
知识库管理
/knowledge
安全漏洞模式、编码规范、修复建议、历史评估四大知识库，支持语义检索和 RAG 增强分析。
系统管理
系统配置
/system/config
评估参数、大模型 API、环境类型和保留策略管理。
