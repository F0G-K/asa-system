认证与系统
登录页
/login
用户登录，输入用户名和密码进入系统。
认证与系统
系统初始化
/system/init
首次使用时创建管理员账户。
认证与系统
403 无权访问
/403
没有访问权限时显示的页面。
认证与系统
404 页面不存在
/:pathMatch(.*)*
访问不存在的页面时显示。
项目管理
项目列表
/projects
查看所有安全评估项目，支持筛选、排序和分页。
项目管理
创建项目
/projects/new
登记源码信息与评估任务范围。
项目管理
项目详情
/projects/:projectId
项目基本信息、评估任务、运行环境和统计概览。
实时监控
实时监控
/projects/:projectId/monitor
评估阶段进度、角色任务、消息和日志实时查看。
漏洞管理
漏洞列表
/projects/:projectId/vulnerabilities
项目发现的漏洞列表，支持风险等级和验证状态筛选。
漏洞管理
漏洞详情
/projects/:projectId/vulnerabilities/:vulnId
漏洞基本信息、影响范围、触发条件和复现步骤。
攻击路径
攻击路径列表
/projects/:projectId/attack-paths
将漏洞串联成攻击链路，展示攻击者可能的渗透路径。
攻击路径
攻击路径详情
/projects/:projectId/attack-paths/:pathId
攻击步骤时间线，每步关联具体漏洞。
报告
评估报告
/projects/:projectId/report
评估报告预览与下载，支持 Markdown 和 HTML 格式。
系统管理
系统配置
/system/config
评估参数、大模型 API、环境类型和保留策略管理（管理员）。
