# 自动化安全评估系统（ASA System）

> 一个"自动给代码做安全体检"的系统。

## 这是什么？

传统上，检查代码有没有安全漏洞需要安全专家一行一行地读代码——搭环境、找漏洞、验证漏洞、梳理攻击路径、写报告，全程依赖人工，费时费力。

这个系统把上述流程全部自动化：**你把源码给它，它就在隔离沙箱里用 AI 自动跑完整套安全评估流程，最后给你一份漏洞报告**。

## 怎么工作的？

```
提交源码 → 创建项目 → 启动任务 → 隔离环境自动分析 → 生成报告
```

分析过程分 **4 个阶段**，按顺序自动推进：

| 阶段 | 做什么 |
|------|--------|
| 环境扫描 | 识别项目用了什么技术栈、依赖库、目录结构 |
| 代码分析 | 遍历源码，找出潜在漏洞（SQL 注入、XSS、权限绕过等） |
| 漏洞验证 | 验证漏洞是否真的能被利用，提取证据和复现步骤 |
| 报告生成 | 汇总所有漏洞、攻击路径和修复建议，生成标准化报告 |

系统内部有 **6 个 AI 角色**协作干活（环境检查、代码分析、漏洞验证、报告整理等），调度器按阶段把任务分给对应角色。

## 有哪些板块？

从使用者角度看，分成 **7 个主要板块**：

| 板块 | 干什么的 |
|------|----------|
| **账号管理** | 登录注册、权限控制（普通用户/管理员） |
| **项目管理** | 入口——创建项目、指定源码来源、启动/停止分析 |
| **安全分析引擎** | 核心大脑——按阶段自动推进环境扫描→代码分析→漏洞验证→报告生成 |
| **隔离沙箱** | 每个项目跑在独立 Docker 容器里，源码只读挂载，保证安全隔离 |
| **漏洞管理** | 展示所有发现的漏洞，标注风险等级（致命/高危/中危/低危）、附带证据和复现步骤 |
| **攻击路径** | 把多个漏洞串成完整攻击链路，展示攻击者如何一步步深入 |
| **实时监控** | 分析过程中实时推送进度、日志、资源消耗等信息 |

还有一个管理员专属的 **系统配置** 板块，用来调超时时间、并发数量等参数。

## 技术栈概览

| 层次 | 选型 |
|------|------|
| 前端 | Vue 3 + TypeScript + Element Plus + Vite |
| 后端 | FastAPI (Python 3.12) + Celery + SQLAlchemy |
| 数据库 | PostgreSQL 16 + Redis 7 |
| AI 编排 | LangGraph + OpenAI 兼容适配层 |
| 隔离环境 | Docker 容器，非 root 运行，只读根文件系统 |
| 部署 | Docker Compose + Nginx |
