# 自动化安全评估系统（ASA System）

> 一个"自动给代码做安全体检"的系统。

## 解决了什么问题？

源码安全评估（审计）这件事，传统上需要安全专家手动做：搭环境 → 读代码 → 找漏洞 → 验证漏洞 → 梳理攻击路径 → 写报告。全程依赖人工，过程不透明、标准不统一。

本系统把上述流程串起来，做成一个 Web 工作台——用户只需要把源码交给它，它就在隔离环境里自动跑完整个安全评估流程，最终产出漏洞清单、攻击链路和一份标准报告。

## 核心流程

```
提交源码 → 创建项目 → 启动任务 → 隔离环境自动分析 → 生成报告
```

分 5 个阶段：

| 阶段 | 做什么 |
|------|--------|
| `environment_scan` | 扫描项目用了什么技术栈、依赖库、运行环境 |
| `code_analysis` | 遍历源码找潜在漏洞（SQL 注入、XSS、权限绕过等） |
| `vulnerability_verify` | 验证漏洞是否真的能利用，提取证据和复现步骤 |
| `report_generate` | 汇总所有漏洞 + 攻击路径 + 修复建议，生成报告 |
| `done` | 结束 |

系统内部有 **6 个 AI 角色**在协作：通用处理、环境检查、代码分析、漏洞验证、报告整理、运维辅助。任务调度器按阶段把工作分发给对应角色。
